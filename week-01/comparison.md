## 3. What the AI added that I never asked for

- Interactive UI components: Score Distribution bar chart, Per-Mark breakdown table, and Pass/Fail threshold slider.
- Real-time input parsing and visual badging for individual marks.

## 4. What the AI got wrong or silently skipped

- Output decimal formatting: The initial UI rounded numbers to 1 decimal place (67.0) instead of strictly adhering to 2 decimals (67.00) required by the specification.

## 5. The defect I asked Rocket to fix

**Prompt I used:**
"Make sure the average score and pass rate formatting always strictly display two decimal places (e.g. 67.00% instead of 67.0%) for better presentation consistency."

**Result:** Fixed.

**What this tells me:**
AI tools excel at generating feature-rich web applications out of the box, but exact formatting details require minor human refinements.

## 6. Reflection (200–300 words)

1. **Which parts of the work did the AI genuinely speed up?**
AI drastically reduced setup time for building a complete graphical interface. Creating an interactive web form with live chart visualization, status badges, and styled components manually would have taken hours, whereas Rocket generated it in under three minutes.

2. **Where did the AI cost you time, or give you something that looked right but was not?**
The AI added a significant amount of complex frontend boilerplate code (React components, state hooks, styling libraries) that was unnecessary for a simple calculation task. Verifying that the complex UI didn't silently miscalculate statistics required careful step-by-step testing.

3. **Which of these two artefacts would you be willing to put your name on, and why?**
I would gladly put my name on both. The manual Python script demonstrates clean, fundamental algorithm design and exact control over input validation. The Rocket web app demonstrates modern rapid-prototyping capabilities that provide an excellent user experience.

4. **What must a human engineer still be responsible for after this experiment?**
A human engineer remains strictly responsible for defining explicit requirements, verifying edge-case handling across test sets, and ensuring that automatically generated visual interfaces strictly comply with technical specifications.
